## Что за проект

Сайт застройщика «Хороший дом» (Краснодар): продаём **готовые кирпичные дома с участком** в своих посёлках. Next.js 16 + Payload CMS, SQLite (`platform.db`), стили — обычный CSS.

**Позиционирование (согласовано с собственником Александром):** в первую очередь продажа готовых домов. Строительство — вторично: только на доступной земле в наших посёлках и только по нашим типовым проектам. Упора на «Построить дом» в интерфейсе нет.

## Как запустить (важно, здесь были грабли)

```bash
cd <этот репозиторий>
npm install
PORT=7100 npm run dev
```

- Открывать: **http://horoshiy.localhost:7100/** (браузер сам резолвит `*.localhost` в loopback, ничего в hosts писать не надо).
- `.env`: `NEXT_PUBLIC_ROOT_DOMAIN=horoshiy.localhost:7100` — кнопки ведут на этот домен, поэтому сайт должен работать именно на нём и на порту 7100.
- **Порт 3000 не использовать**: его постоянно занимает встроенный сервер Kimi, из-за этого открывалась старая версия. Дефолт `npm run dev` — 3100, но для этого проекта всегда `PORT=7100`.
- Карточка превью Kimi работает нестабильно — пользоваться прямой ссылкой.
- Проверка типов: `npx tsc --noEmit`. Коммиты по-русски, ветка `redesign-v2` синкается в origin автоматически (hook).

## Текущее состояние главной (home-v2.tsx)

Кадр «ночь → рассвет → день → вечер»: HeroNight → посёлки (EstateCovers) → готовые дома (HouseFilm) → 3D-генплан (PlotPicker) → что входит в цену (Included) → команда (Founder/Residents) → строительство вторым планом (BuildTeaser) → вечерний финал с формой (EveningFinale, его вайб Игорю нравится, «ГТА 6»).

**Первый экран (HeroNight.tsx + блок `.hn` в `src/app/(frontend)/v2.css`), итог итераций 10.11:**
- Чистое кино: ночь, дом, падающая комета. Из текста — только «Хороший дом» + «сюда приводят мечты».
- Дом — кликабелен: тонкая контурная обводка в цвете шрифта (статичная, без пульсации и ореолов), клик = зум с тёплой вспышкой → `/catalog`. Чип «Выбрать дом →» на десктопе по ховеру, на телефоне виден сразу.
- Свет в окнах зажигается сразу после первого пролёта кометы (`hn-windows-on`, синхронизировано с `hn-star`).
- Подсказка свайпа: анимированная линия со стрелкой внизу по центру, без слов; при рассвете темнеет.
- Шапка, плавающая «Заказать звонок» и мобильная нижняя панель скрыты на первом экране и появляются после скролла — контракт `html.past-hero` (тот же, что у HeroOpen/`.h6`); герой уходит под шапку через `margin-top: calc(var(--header-h) * -1)`.
- Скролл гасит ночь в утреннее фото (`--p` от скролла, `is-day` после середины).
