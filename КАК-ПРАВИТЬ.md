# Как вносить правки после переговоров

Сайт задуман как сильный макет: ТЗ заказчика вносим поверх, наши идеи остаются. Почти всё, о чём обычно просит заказчик, меняется **в админке без кода**. Остальное лежит в одном понятном файле, указанном ниже.

Админка: `/admin`, логин в `platform/.env`. На главной админки — «Как вести сайт»: частые дела со ссылками прямо в нужные формы, у каждой роли свои (`src/components/admin/Guide.tsx`).

Стиль (19.10): без декоративных градиентов и свечений, ровные цифры, тексты — факты из материалов клиента. Цвета-токены `--grad-*` в `globals.css` теперь плоские; вернуть градиенты — вписать их туда же.

## 1. Меняется в админке (заказчик может сам)

| Что попросят | Где |
|---|---|
| Цены, статусы «свободен / продан», новый дом | Дома. Новый дом: посёлок, проект, тип, площадь, цена — спальни и особенности подставятся из проекта, без фото покажем фото проекта (`tools/admintest.py`, ~1 минута) |
| Посёлок распродан | Посёлки → статус «Продажи завершены»: все его дома сами станут «Продан». На сайте: «продан · N домов» как масштаб компании, в конце списков, в «О компании» — блок «Уже построили и продали» |
| Новый посёлок до старта продаж | Посёлки → статус «Скоро»: без цифр и генплана, форма «Узнать о старте продаж» (заявка «на будущее» с этим посёлком) |
| Фото и планировка дома | Дома → фото / план; без фото берётся фото проекта |
| Новый посёлок, описание, инфраструктура | Посёлки |
| Генплан посёлка, номера участков | Посёлки → «Генплан (раскладка)», Дома → «Участок на генплане, №» |
| Заставка 3D-генплана | Посёлки → «Заставка 3D-генплана» |
| Новый регион, «скоро» или «продаём» | Регионы → статус |
| Телефон и офис региона, Telegram менеджера для заявок | Регионы → офис |
| Кружки на плане и видео комнат | Проекты → «Точки на плане»: подпись, x/y в % от картинки, видео. Без видео кружок открывает карточку «Здесь будет видео этой комнаты» |
| Расчёт «1 ребёнок / 2 ребёнка» для дома | Дома → «Расчёт ипотеки для этого дома» |
| Ставка, срок, лимит семейной ипотеки | Компания → «Семейная ипотека» |
| Ценности, преимущества, отделка, вопросы | Компания → «Ценности и доверие» |
| Год основания, «домов построено», слоган, главное фото | Компания → «Бренд и контакты» |
| Акции (на всех или в одном регионе, со сроком) | Акции |
| Заявки и что интересует клиента | Заявки: дом, посёлок, источник (реклама по UTM и клик-ID Директа и VK, поиск, другой сайт, прямой заход) и первая страница визита заполняются сами. Справа — статус Telegram и amoCRM |
| Страница под рекламу (Директ, VK) | Промо-страницы → создать: заголовок как в объявлении, посёлок, оффер, до 4 цифр. Адрес: `krd.домен.ru/p/<адрес>`. Заявки с неё помечены «Промо «…»» |
| Сотрудники и роли | Сотрудники (только администратор): «Контент-менеджер» — дома, посёлки, проекты, фото, акции, промо; «Отдел продаж (РОП)» — заявки и статусы домов; «Менеджер региона» — всё своего региона. Настройки, регионы и сотрудники видит только администратор |

## 1а. Подключения (файл `.env` на сервере, образец — `.env.example`)

| Что | Переменные | Где взять |
|---|---|---|
| Telegram менеджеру | `TELEGRAM_BOT_TOKEN`, chat_id — в админке у региона | @BotFather; chat_id — инструкция в `.env.example`. `TELEGRAM_PERSONAL_DATA=0` — без имени и телефона (решает юрист клиента) |
| amoCRM | `AMO_DOMAIN`, `AMO_TOKEN`, при желании `AMO_PIPELINE_ID`, `AMO_STATUS_ID` | amoCRM клиента → Настройки → Интеграции → долгосрочный токен. Без них заявки живут в админке и Telegram; если amoCRM не отвечает — очередь, повтор каждые 5 минут |
| Яндекс Метрика | `NEXT_PUBLIC_YM_ID` | номер счётчика; цели: `lead_submit`, `phone_click`, `messenger_click` |
| VK Реклама | `NEXT_PUBLIC_VK_PIXEL_ID`, адрес скрипта — `NEXT_PUBLIC_VK_PIXEL_SRC` | код пикселя в кабинете VK Рекламы. Те же цели |

`NEXT_PUBLIC_*` вшиваются при сборке: после правки — `npm run build`.

Правка в админке видна на сайте со следующего обновления страницы: главная, каталог, «Локации», «О компании», регионы, посёлки и дома рендерятся на каждый запрос, остальные страницы сбрасывают кэш при сохранении (`src/collections/revalidate.ts`).

Если поле пустое, сайт не показывает дыру или прочерк, а прячет блок. Это проверяет `tools/emptytest.py`: голый регион, пустой посёлок, дом без фото.

## 2. Меняется в коде (5–30 минут)

| Что | Файл |
|---|---|
| Главная: первый экран, два пути + полоса «Где это всё» (локации), порядок блоков | `src/app/(frontend)/(main)/page.tsx` |
| «Построить»: 5 причин доверять (дом строится под ними) | `src/app/(frontend)/(main)/build/page.tsx`, массив `points` |
| Длина прокрутки «Построить» | `globals.css` → `.story__flow` (`gap`, `padding`) |
| Названия этапов в плашке над 3D | `src/components/BuildStory.tsx` → `STAGES` |
| Страница дома (порядок: фото → план → цена → ипотека) | `src/app/(frontend)/r/[region]/houses/[code]/page.tsx` |
| Меню бренда, региона, региона «скоро» | `src/components/Shell.tsx` |
| Тексты формы заявки и варианты «что интересует» | `src/components/LeadForm.tsx` |
| Цвета, шрифты, отступы | `src/app/(frontend)/globals.css` → `:root` |
| 3D-дом на «Построить» | `src/components/BuildHouse3D.tsx`, модель — `src/lib/house3d.ts` |
| 3D-генплан посёлка | `src/components/Genplan3D.tsx` |

## 3. После любой правки — прогнать проверки

Сначала `npm run dev`, затем:

```
python tools/smoke.py        # 40 проверок: страницы, переадресации, заявки
python tools/crawl.py        # весь сайт: битые ссылки и картинки, якоря, title, «undefined», склонения
python tools/hiddentest.py   # черновики скрытого региона не видны на общих страницах
python tools/emptytest.py    # пустые записи в админке не ломают страницы (сам создаёт и удаляет «Тестовый край»)
python tools/buildtest.py    # «Построить»: дом готов за ≤3 экрана, карточки не закрывают дом на телефоне
python tools/housetest.py    # кружки на плане: карточка «видео скоро» и видео (на временных роликах)
python tools/meetingtest.py  # после встречи 14.10: «Южный ветер» продан, Нововеличковская «скоро», заявка с домом и источником
python tools/admintest.py    # новый дом через админку за минуту → на сайте
python tools/landingtest.py  # промо-страницы: содержимое, 404, sitemap, заявки с обеих форм помечены промо
python tools/rolestest.py    # роли: контент-менеджер и РОП видят и могут только своё
python tools/designshots.py now  # снимки ключевых страниц (компьютер и телефон) — посмотреть глазами
python tools/shots.py check  # снимки всех страниц + ошибки консоли
npx tsc --noEmit; npx eslint src
```

С подставными сервисами (сервер запускается с переменными из шапки теста):
```
python tools/crmtest.py        # amoCRM недоступна → очередь → снова доступна → ушло; Telegram; клик-ID VK
python tools/analyticstest.py  # Метрика и VK работают; заблокированы — заявка всё равно с источником
```

`emptytest.py`, `promotest.py`, `housetest.py`, `meetingtest.py`, `admintest.py`, `landingtest.py`, `rolestest.py`, `crmtest.py` и `analyticstest.py` на время работы создают тестовые записи и видны на сайте, потом удаляют их за собой. Не запускать, пока сайт кому-то показывают или пишется видео.
