2. **Не трогать:** `src/payload.config.ts`, `src/collections/Users.ts`, `src/collections/access.ts`, `.env`, `platform.db`, историю git (никаких force-push/rebase). Удалением страниц/файлов занимается Илья — мы ничего не удаляем, максимум скрываем.
3. **Не менять стек и не делать масштабный рефакторинг.** Next.js 16 (App Router, Turbopack) + Payload CMS 3 + SQLite. Библиотек анимации нет и не добавляем: весь motion — самописный (CSS-ключи, rAF, View Transitions, three.js там, где уже есть). Не ломать работающие механики ради референсов.
4. Работа только в ветке `igor/<что-делаю>`, маленькие шаги, один коммит — одна правка, в конце Pull Request с описанием «что поменял и как проверил».
5. После каждой правки: `npx tsc --noEmit` без ошибок + страница открывается в браузере + релевантные проверки (раздел «QA»).
6. Автотесты `tools/*.py` написаны под Windows (жёстко зашит путь к Edge в `tools/cdp.py:11`) и на macOS не запускаются. Проверка — вручную через браузер и curl по чек-листу QA. Починка `tools/cdp.py` — отдельная задача, только с согласия Ильи.
7. В рабочей копии все файлы с концами строк CRLF, Git видит изменёнными все 204 файла. **Перед правкой каждого файла нормализуй его концы строк в LF** (`sed -i '' 's/\r$//' <файл>`) — поведение не меняется, диф в PR становится чистым. Это часть правки, упомяни в коммите.
8. `РЕШЕНИЯ.md` содержит один битый байт (NUL) посередине файла — из-за него он «бинарный». Не редактируй его в этом задании; починка — отдельным мини-коммитом (убрать один NUL-байт).

## 1. Контекст продукта

- **Продукт:** сайт-платформа застройщика кирпичных домов для круглогодичной жизни. Посёлки (6), проекты домов (12 типов), готовые дома (29 в базе), ипотека, генпланы, промо-страницы под рекламу, заявки → Telegram + amoCRM.
- **Аудитория:** семьи со средним и выше среднего доходом, покупают дом для жизни (не инвестиция). Цены от ~8,8 млн ₽.
- **Бренд:** тёмно-зелёный + золото + молочный, Cormorant Garamond (антиква) + Manrope, слоган «Сюда приводят мечты». Стиль 19.10: без градиентов и свечений, ровные цифры, тексты — факты, не слоганы.
- **Позиция:** живое вместо нарисованного. Реальные фото построенных домов — главное преимущество (у ключевого референса ERA Residence их нет: там продают по рендерам). Антон (сторона клиента) против «нейроконтента»: никаких GPT-картинок без подписи и подписей-фантазий.
- **Бизнес-цель:** заявка на показ/подбор дома. Каждый приём на сайте либо ведёт к выбору дома, либо не мешает ему.

### Структура сайта (проверено аудитом)

Главный домен: `/` (главная), `/catalog`, `/build`, `/projects` + `/projects/[slug]`, `/about`, `/mortgage`, `/contacts`, `/locations`, `/privacy`, `/consent`, `/preview/[variant]` (служебная).
Поддомен региона `krd.…`: `/` (регион), `/catalog`, `/objects/[slug]` (посёлок), `/houses/[code]` (дом), `/p/[slug]` (промо).
Служебные роуты: `/robots.txt`, `/sitemap.xml`, `/llms.txt`, `/realty.xml`, `/admin`, `/api/*`.

### Что уже реализовано (не переделывать, беречь)

- **Все ключевые механики референсов уже есть и работают:** гигантская типографика поверх фото (hero-5 «Vintara», выбран в админке); построчное/пословное появление заголовков (`Words.tsx`); золотая нить SVG с прорисовкой при скролле (`Thread.tsx`); сборка дома при прокрутке на WebGL (`BuildHouse3D.tsx`, план «Тип 5» обведён по реальному плану клиента); «рука с планом → каркас → дом» (`SketchToHouse`); веер проектов (`ProjectFan`), веер фото (`HouseStack`); слайдер «чертёж ↔ дом» с мышью/тапом/стрелками и aria (`DraftSplit`); наклон карточек за курсором (только мышь, `PageMotion.tsx`); плавные переходы между страницами (View Transitions + «полёт фото»); планировка с видео-кружками (`PlanTour`, видео по клику, заглушки «видео скоро»); «3D-вид» планировки («Тип 5», подпись «мебель для примера»); интерактивный 3D-генплан с фильтрами, ценниками, fly-to и morph-переходом на страницу дома (`Genplan3D`), есть 2D-fallback «Схема».
- **Производительность продумана:** three.js грузится по IntersectionObserver, рендер останавливается вне вьюпорта, видео `preload="none"`, картинки с resize (640/1600), ленивая загрузка, нет файлов >800 КБ.
- **Доступность неплохая:** `prefers-reduced-motion` обработан везде, aria у слайдеров/фильтров/диалогов, подписи полей формы, один h1, исправленные уровни заголовков.
- **Честные подписи уже есть:** «Визуализация проекта» у «Тип 12» (рендер с бассейном) в каталоге и на странице дома; «мебель для примера»; «Пример: построенный дом…» у Нововеличковской; «Мебель на макете — для примера: дом сдаём с предчистовой отделкой» на /build.
