# Видео прототипа для «Хорошего дома» — сценарий записи

Для кого: Александр, Антон и их РОП. Видео пересмотрят и покажут партнёрам, поэтому записываем только по маршруту ниже. Длина — **3,5–4 минуты**. Тон — как на встрече 14.10: «это черновик на ваших данных, боевой сайт будет на вашем контенте».

## Подготовка (10 минут)

1. **Запустить прод-сборку** (быстрее dev, нет значков разработки):
   ```
   cd platform
   npm run build
   npm start
   ```
   Если на :3000 уже работает `npm run dev`, сначала остановить его: `Get-NetTCPConnection -LocalPort 3000 -State Listen` → `Stop-Process -Id <OwningProcess>`.
2. **Не запускать тесты** во время записи: они создают тестовые записи.
3. **Браузер:** Edge или Chrome, обычное окно (не инкогнито), масштаб 100 % (Ctrl+0), окно 1440×900 или 1920×1080 на весь экран. Закрыть лишние вкладки и панель закладок (Ctrl+Shift+B).
4. **Прогреть страницы:** открыть по разу все адреса из таблицы, на «Динской» нажать «Открыть 3D» и дождаться домиков. Потом закрыть всё, кроме вкладок по порядку:
   1. http://horoshiy.localhost:3000/
   2. http://horoshiy.localhost:3000/admin — войти заранее (логин и пароль: `SEED_ADMIN_EMAIL` и `SEED_ADMIN_PASSWORD` в `platform/.env`). Открыть «Дома», отфильтровать посёлок «Динская».
5. **Заявки в админке** должны быть пустыми (там только то, что оставите во время записи).
6. **Звук:** гарнитура или тихая комната. Говорить можно поверх записи сразу или записать без звука и наложить голос потом.

**Как записать:** Win+Alt+R (Xbox Game Bar, уже есть в Windows) пишет активное окно; повторное Win+Alt+R — стоп. Файл появится в «Видео → Клипы». Если Game Bar не пишет браузер — Win+G → «Записать».

## Фразы, на которые клиент отзывался на встрече

- «Хотел сказать, что новый поселок вы можете завести сами за 10 минут без нас».
- «И если поменять статус на занят, на продан, то сразу поменяется цвет в 3D модели».
- «На один слайд, на одну страницу должно быть одно вау».

## Чего в кадре быть не должно

Цен вариантов КП, чужих роликов, тестовых заявок, «Южного ветра» в продаже, утверждений о числе свободных домов как о факте. Москву и море не показывать: ближайшие 1–2 года у клиента — Краснодар.

## После записи — вернуть как было

1. Админка → дом **di-tip5-v3** → статус **«Свободен»** → «Сохранить».
2. Админка → «Заявки» → отметить тестовую заявку → «Удалить».
3. Если открывали «Создать новый» и случайно сохранили — удалить этот дом.
4. Посмотреть видео целиком: нет ли в кадре уведомлений Windows, вкладок с личным, пароля.
