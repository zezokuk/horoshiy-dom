## Как всё держится актуальным

Ветка `redesign-v2` обновляется сама: правки Ильи уходят в репозиторий при завершении работы Claude и после каждого коммита. Перед отправкой `tools/sync.mjs` проверяет типы, ищет ключи и закрытые файлы, забирает чужие коммиты. Что отправить нельзя, остаётся на компьютере, а причина выводится на экран. В `main` и другие ветки ничего не уходит, принудительной отправки нет.

| Кому | Что сделать |
|---|---|
| **Игорь: видеть правки на своём сайте** | `git checkout redesign-v2`, затем в двух окнах `npm run dev` и `npm run live`. Новые правки приходят раз в 30 секунд, страница обновляется сама |
| **Игорь: просто посмотреть список** | [История ветки на GitHub](https://github.com/zezokuk/horoshiy-dom/commits/redesign-v2) или журнал в [СЕЙЧАС.md](СЕЙЧАС.md) |
| **Kimi** | [KIMI.md](KIMI.md) велит ей в начале работы выполнить `git pull` и прочитать СЕЙЧАС.md |
| **Илья: новый компьютер** | один раз `node tools/sync.mjs install`, а в `.claude/settings.local.json` — хук `Stop` с командой `node tools/sync.mjs push --claude` |

Тексты, цены и фото в админке этим путём не ходят: база у каждого своя (см. ниже).

## Запуск на своём компьютере (15 минут)

Нужно: [Node.js 20 или 22 LTS](https://nodejs.org) и Git.

```bash
git clone <адрес репозитория> horoshiy-dom
cd horoshiy-dom
npm install
cp .env.example .env        # Windows: copy .env.example .env
```

В `.env` замени `PAYLOAD_SECRET` на любую длинную строку. Ключи Метрики, VK, Telegram и amoCRM оставь пустыми: локально они не нужны.

```bash
npm run seed    # заполнит базу: 6 посёлков, 12 проектов, 29 домов, фото (≈1,5 минуты)
npm run dev
```

Seed напечатает логин и пароль админа и сохранит их в `.env`.

| Что | Адрес |
|---|---|
| Главная | http://horoshiy.localhost:3000 |
| Регион Краснодар | http://krd.horoshiy.localhost:3000 |
| Админка | http://horoshiy.localhost:3000/admin |

Адреса `*.localhost` работают в Chrome, Edge и Firefox без настройки. Первая загрузка страницы в режиме разработки идёт 10–30 секунд, потом быстрее.

## Как вносить правки без сломанного телефона

- **Тексты, фото, цены, статусы** правятся в админке. Пока сайт не выложен, у каждого своя база на компьютере: правка в твоей админке до Ильи не дойдёт. Поэтому до запуска такие правки — через Issue (ниже).
- **Хочешь что-то поменять, но не в коде** → GitHub → Issues → New issue: что, где (адрес страницы и скриншот), почему. Илья делает и закрывает issue ссылкой на коммит.
- **Правишь код сам (или через нейросеть)** → своя ветка `igor/<что-делаю>` → Pull Request. В `main` напрямую не пушим. В описании PR: что поменял и как проверил.
- **Новое решение** (договорились с клиентом, выбрали вариант) → строка в [РЕШЕНИЯ.md](РЕШЕНИЯ.md) с датой. Старые строки не стираем, а помечаем «заменено».
- **Факты о клиенте** (цифры, сроки, «газ подключён») пишем только из материалов клиента. Нет подтверждения — ставим `___` и задаём вопрос.

## Где что

| Папка | Что внутри |
|---|---|
| `src/app/(frontend)` | страницы сайта |

Чего нет в репозитории (так и надо): `.env` с ключами, база `platform.db`, папка `media` — всё это делает `npm run seed`.

## Редизайн v2 (ветка `redesign-v2`, 29.10.2026)

Светлый вид после созвона 27.10: белый фон, зелёный «Листва», заголовки Forum, текст Golos, новая главная из 9 экранов (`src/app/(frontend)/(main)/home-v2.tsx`, компоненты `src/components/home/`, первый экран `src/components/heroes/HeroOpen.tsx`, стили `src/app/(frontend)/v2.css`). Старый тёмный вид не удалён — переключается в админке «Внешний вид».

Как поднять у себя:
1. `git fetch && git checkout redesign-v2`, затем `npm run dev` — новые поля схемы (основатель, офисы, порядок экранов) добавятся сами.
2. Включить v2: `npx payload run tools/look.ts` (вернуть старое: `npx payload run tools/look.ts forest hero-5`). То же — в админке «Внешний вид»: «Цвета» → «v2 · A «Листва»», «Первый экран» → «… на весь экран (v2)».
3. Цены из прайса 27.10 (если база из сида): при запущенном сервере `python tools/price_27_10.py` (план), `--apply` (запись), `--undo` (откат). Нужны SEED_ADMIN_EMAIL и SEED_ADMIN_PASSWORD в `.env`.

Что ждёт клиента: фото основателя (поле «Компания → Кто строит и офисы»), обложки в исходнике, генпланы с номерами, вечерний и широкий рендер для первого экрана (промпты — `БАЗА/Промты/lark/`), картинки сцен в `public/design/scenes/{breakfast,lawn,grill,car,fireplace,snow}.webp` — появятся на главной сами.

Если при первом запуске ветки сервер падает с `no such column: home_order` (баг миграции SQLite у Payload/drizzle): остановить сервер, сделать бэкап `platform.db`, удалить пустую временную таблицу и добавить колонку руками — в sqlite3: `DROP TABLE IF EXISTS __new_design; ALTER TABLE design ADD COLUMN home_order text DEFAULT 'founder';` — затем снова `npm run dev`.
